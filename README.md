# Tusher Chandra Mondol — Portfolio

A lightweight two-page static portfolio for Netlify/GitHub Pages.

## Pages
- `index.html` — research/professional portfolio
- `explore.html` — travel, parks, hiking, sports, and personal interests

## Before publishing
Search the project for these placeholders and replace them with your real links:
- `YOUR_RESUME_URL`
- `YOUR_GOOGLE_SCHOLAR_URL`
- `YOUR_ORCID_URL`
- `YOUR_INSTAGRAM_URL`

For the Explore page, replace the `—` counters and placeholder travel/park/hike cards as you build your journey. Photos can be added later under `assets/`.

## Local preview
From the project directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Netlify
Connect this GitHub repository to Netlify. This is a static site, so no build command is required and the publish directory is the repository root.
